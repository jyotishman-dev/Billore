Preparing and exporting return data is different from filing directly on the GST portal. Direct filing or live e-invoice / e-Way Bill connectivity depends on eligible integrations, credentials and applicable provider arrangements.

Multi-device access needs a hosted setup and careful data synchronisation. The underlying open-source project is offline-first, so confirm that cloud sync and account-based access have been built before selling them as plan features.

The product roadmap should preserve practical exports and backups. Exact formats, retention periods and migration support depend on the release and plan you publish.
